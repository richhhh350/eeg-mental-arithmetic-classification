# Python V2 第三阶段：降采样桥接与 EEGNet

冻结日期：2026-10-08。第二阶段已发布至 GitHub 提交 `134476155abfa8ce06f472747de38e00bf1237c7`。完成登记（2026-10-09）：本阶段180个传统模型与108个EEGNet模型全部完成并通过独立审计，详见[完整报告](v2-stage3-report.md)。下列训练规则保持冻结版本不变。

## 问题与范围

在保持同一批36名被试、每条件前60秒、2秒非重叠窗口和无目标校准的情况下，检验紧凑时空卷积表征的跨被试表现。先量化降采样和频率网格变化对传统模型的影响，再对照 EEGNet。保留 MATLAB V1、阶段一与阶段二的原始结果。

本阶段不以达到某一准确率为验收条件，也不启动目标校准、CORAL、DANN、额外ICA或UMAP。数据供应方原有清洗、无事件确认的任务起点和固定条件顺序等局限继续保留。

## 数据与抗混叠

所有 EDF 哈希、500 Hz原始数据、19通道顺序、2秒窗口ID和500 Hz DE特征必须与第一阶段逐点一致。对平均参考、窗口去均值后的每个独立窗口，使用固定FIR与 `resample_poly` 从500降至128 Hz，输出19×256，并在本窗口内再次去均值。CNN实际输入保留float32；128 Hz DE从相同float32样本计算。

- 比率32/125；2501抽头对称FIR，Kaiser β=5，归一化截止1/125。
- 固定FIR由升采样域定义，半支持长度对应原始39.0625点，即0.078125秒。
- 填充模式 `reflect`，只读取当前2秒窗口，不能借用相邻窗或目标记录其他片段。
- 不额外裁边：全部模型共享原窗口区间。反射仍可能影响边缘估计；这是整窗离线处理，不能称作逐采样点因果滤波。
- 合成10/30 Hz信号的内部幅值误差须小于0.2 dB；100/150 Hz抑制须超过40 dB。内部检查去掉首尾各16个输出点，同时报告全窗RMS，避免把内部检查当作全窗边界性能。

SciPy 的多相重采样包含低通FIR；其填充和滤波器定义见[官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)。

## 五组传统桥接

| 配置 | 目的 |

| 原500 Hz DE+LR，NFFT=1024 | 再现第一阶段2160条预测 |
| 500 Hz DE+LR，NFFT=1000 | 单独改变FFT网格至0.5 Hz |
| 128 Hz DE+LR，NFFT=256 | 在相同0.5 Hz网格下查看降采样影响 |

| 128 Hz DE+SVM | 同采样率传统模型对照 |

均保留原θ/α/β定义、原参数候选和3折按源被试分组验证。128 Hz是提前指定的EEGNet输入率，不根据上述外层成绩重新挑选。CNN使用降采样后的宽频时域输入，DE只保留4—30 Hz特征；差异包含表征与模型两方面，不能只归因于网络结构。

## EEGNet 与训练规则

采用本地 PyTorch 实现的 EEGNet-8,2，依据[原论文](https://arxiv.org/abs/1611.08024)、[作者实现](https://github.com/vlawhern/arl-eegmodels/blob/master/EEGModels.py)及[Braindecode参数说明](https://braindecode.org/stable/generated/braindecode.models.EEGNet.html)核对层级含义。

F1=8、D=2、F2=16；时间核64点，分离卷积时间核16点；普通Dropout=0.5；ELU；平均池化4/8；BN eps=0.001、PyTorch momentum=0.01；空间卷积最大范数1、分类器最大范数0.25，每次优化后投影。偶数核使用左右不对称 SAME 填充。共1666个可训练参数。采用PyTorch默认初始化，不宣称与作者的TensorFlow实现或Braindecode实现数值等价。

每个外折留出1人，剩余35人用3折GroupKFold。每个内折仅在其训练人群上拟合每通道均值和标准差，按源验证被试BA等权均值选择轮数。外层目标不进入标准化、选轮数或训练函数。

Adam学习率0.001，weight decay=0，batch=128。每轮将训练集完整随机排列一次；每个被试/条件均30窗，因此每轮对被试和类别严格等权，无重复抽样、丢弃尾批或数据增强。

- 固定种子13、42、2026。内折种子为基础种子+10000×(折序号+1)，最终重训使用基础种子。
- 最多60轮；至少运行15轮，连续12轮源验证均值无严格改善则停止。
- 并列最优取最早轮，容差1e-12；三内折最优轮数取中位数。
- 然后重新初始化，在全部35人上训练该轮数。没有目标早停或“最好种子”选择。
- 开启确定性算法；每任务独立进程、2个PyTorch线程。可并行运行最多4个任务，不承诺跨软件版本或硬件逐位相同。
- 测试强制 `eval()` 与 `inference_mode()`，逐项断言所有参数和BN缓冲区未变；心算概率阈值固定0.5。

**预先记录的资源调整。**原总计划建议150轮/patience20并优先考虑Braindecode。当前独立环境使用官方CPU版PyTorch 2.14.1+cpu。合成1440窗测时为每轮约0.50秒（4线程）或0.75秒（2线程），尚未观察真实第三阶段成绩时，将首轮上限固定为60轮/patience12，采用便于审计的本地PyTorch实现。后续报告触及上限的频次；不能据此声称网络已充分调优。若以后扩展预算，登记为新实验并同时保留本轮结果。
